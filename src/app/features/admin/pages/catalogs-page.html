Catálogos

RF-083: el administrador gestiona los catálogos del piloto (instituciones, facultades, carreras, ciudades, servicios y reglas). Los cambios no eliminan referencias históricas: las entradas se desactivan.

Las facultades pertenecen a una institución y las carreras a una facultad; el contrato exige ese padre y lo valida. El contrato real no expone reactivación, así que no se ofrece.

Limitación del backend: el alta rechaza siempre la creación (400 con parentId nulo, incluso en categorías planas, y 404 si se envía uno, porque no existe ninguna entrada previa). Se muestra el error real de cada intento.
